# 1v1 Video Call

Private 1 vs 1 video calling application.

## Features

- No sign in
- No registration
- Create room
- Join room
- Room code
- 1 vs 1 JaaS video call
- Camera
- Microphone
- Screen sharing
- Chat
- End call

## JaaS

This project uses 8x8 JaaS.

The JaaS Private Key must NEVER be committed to GitHub.

Store it as:

JAAS_PRIVATE_KEY

in Cloudflare Worker Secrets.
